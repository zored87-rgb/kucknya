# Бэкенд «Кухни» в Google Apps Script

Скрипт живёт внутри Google-таблицы и отвечает приложению. Сервер не нужен, всё бесплатно.

## Что делает

- `setup()` готовит таблицу: переименовывает первый лист в «Холодильник», создаёт листы «Съели», «Покупки», «Оценки», «Мои рецепты», «Настройки», добавляет скрытую колонку `id`, переносит записи из старой таблицы «Съели» и придумывает код доступа. Запускать можно повторно, ничего не задвоится.
- `doPost` принимает запросы приложения: прочитать всё (`bootstrap`) или применить пачку изменений (`batch`).
- `showToken()` — показать код доступа ещё раз. `resetToken()` — сменить код (придётся ввести заново на обоих телефонах).

## Установка (один раз, ~10 минут)

1. Открой таблицу «Холодильник»: <https://docs.google.com/spreadsheets/d/1LC7o3yIus1-5o1fz_DlvmW75Hiq0ZjNEnC3h01mbYCE/edit>
2. Меню **Расширения → Apps Script**. Откроется редактор.
3. Слева файл `Code.gs`. Удали всё, что в нём есть, и вставь содержимое файла [`Code.gs`](Code.gs) из этой папки целиком. Нажми 💾 (Сохранить).
4. Слева ⚙️ **Настройки проекта** → включи галочку **«Показывать файл манифеста appsscript.json»**. Вернись в редактор (значок `< >`), открой `appsscript.json`, замени содержимое на [`appsscript.json`](appsscript.json), сохрани.
5. Вверху в списке функций выбери **setup** → **Выполнить**.
   - Google спросит разрешение: **Проверить разрешения** → выбери свой аккаунт → «Google не проверял это приложение» → **Дополнительно** → **Перейти к проекту (небезопасно)** → **Разрешить**. Это твой собственный скрипт, он получает доступ только к твоим таблицам.
   - Внизу в «Журнале выполнения» появится строка **«Готово. Код доступа для приложения: xxxx-xxxx-xxxx»**. Запиши код — его вводите в приложении.
6. Вверху справа **Начать развёртывание → Новое развёртывание**.
   - ⚙️ рядом с «Выберите тип» → **Веб-приложение**.
   - Описание: `Кухня`.
   - Запуск от имени: **Я**.
   - У кого есть доступ: **Все** (именно «Все», без входа в аккаунт — телефоны заходят без Google-логина; защищает код доступа).
   - **Начать развёртывание**. Скопируй **URL веб-приложения** (заканчивается на `/exec`).
7. Проверка: открой этот URL в браузере — должно показать `{"ok":true,"app":"kukhnya",...}`.

## Обновление скрипта (когда в репозитории новая версия Code.gs)

1. Открой Apps Script, выдели всё в `Код.gs` (Cmd+A), удали и вставь новый [`Code.gs`](Code.gs). Сохрани (💾).
2. **Начать развёртывание → Управление развёртываниями** → ✏️ (карандаш) → Версия: **Новая версия** → **Развернуть**.
   URL и код доступа не меняются, в приложении ничего перенастраивать не нужно.

Новые листы («Входящие», «Чеки», «Цены») появятся сами при первом обращении — setup() запускать не обязательно.

## Если поменяешь Code.gs

**Начать развёртывание → Управление развёртываниями** → ✏️ → Версия: **Новая версия** → **Развернуть**. URL останется тем же.

## Как устроены листы

| Лист | Колонки | Скрытые |
|---|---|---|
| Холодильник | Продукт, Где, Сколько, Годен до, Заметка | id |
| Съели | Дата, Приём, Блюдо, Кто, Понравилось (1-5) | id, recipe_id |
| Покупки | Продукт, Сколько, Причина, Куплено | id |
| Оценки | Блюдо, Крис, Кристина (👍/👎) | recipe_id |
| Мои рецепты | Название, Тип, Кухня, Время, Продукты, Шаги, Яйцо главное | id |
| Настройки | Тип (`кладовая` / `праздник` / `магазин`), Значение, Комментарий | — |
| Входящие | Дата, Текст — что надиктовали через Siri, приложение разбирает и очищает | id |
| Чеки | Дата, Магазин, Сумма €, Заметка | id |
| Цены | Дата, Продукт, Магазин, Цена €, За | id |

Руками в таблицу писать можно: новые строки при следующем открытии приложения получат id сами.

**Свой рецепт** в «Моих рецептах»: в «Продукты» по продукту на строку (в ячейке новая строка — Alt+Enter, на Mac — Ctrl+Option+Enter):

```
Фарш: 500 г
Лук: 2
Курица / индейка: 400 г
Сметана: 3 ст.л. (по желанию)
```

Через `/` — замены, «(по желанию)» — блюдо доступно и без этого продукта.

## Безопасность

Код доступа хранится в «Свойствах скрипта» (Настройки проекта → Свойства скрипта → `TOKEN`), в приложении он не зашит — каждый вводит его на своём телефоне один раз. Без кода скрипт ничего не отдаёт.
