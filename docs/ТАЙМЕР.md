# Таймер, который звонит поверх других приложений

Приложение с экрана «Домой» на iPhone засыпает, когда ты переключаешься в другое. Поэтому его собственный таймер звонит, только пока «Кухня» открыта (или сразу, как только вернёшься). Чтобы таймер звонил всегда — даже на заблокированном экране — «Кухня» может ставить его в стандартные «Часы» через быструю команду.

## Настроить один раз (на каждом iPhone)

1. Открой приложение **«Команды»** → **+**.
2. **Добавить действие** → найди **«Запустить таймер»** → добавь.
3. В действии нажми на время (например, «30 минут») → выбери переменную **«Входные данные команды»**. Единицы — **минуты**.
4. Сверху нажми на название → переименуй в **«Кухня таймер»** (именно так) → **Готово**.
5. В «Кухне»: ⚙️ → **«Таймер в фоне»** → **«Через «Часы»»** → **«Проверить: таймер на 1 минуту»**. В первый раз iPhone спросит разрешение открыть «Команды» — разреши.

## Как это работает

В режиме готовки нажимаешь «⏱ 10 мин» — запускается таймер и в «Кухне», и в «Часах». iPhone на секунду покажет «Команды»; вернуться в «Кухню» — кнопка «◀ Кухня» в левом верхнем углу. Дальше можно уходить куда угодно: звонок будет из «Часов».
