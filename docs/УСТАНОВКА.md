# Как запустить «Кухню» — по шагам

Три части: скрипт в Google-таблице (10 минут), сайт на GitHub (10 минут), установка на два iPhone (по 2 минуты).
Всё бесплатно.

---

## Часть 1. Скрипт в Google-таблице

Подробно с картинками-подсказками — в [apps-script/README.md](../apps-script/README.md). Коротко:

1. Открой таблицу «Холодильник» → меню **Расширения → Apps Script**.
2. Вставь код из `apps-script/Code.gs` вместо того, что там есть. Сохрани.
3. ⚙️ Настройки проекта → включи «Показывать файл манифеста» → вставь `apps-script/appsscript.json`. Сохрани.
4. Выбери функцию **setup** → **Выполнить** → разреши доступ (Дополнительно → Перейти к проекту → Разрешить).
5. Внизу появится **код доступа** вида `abcd-efgh-jkmn`. Запиши его.
6. **Начать развёртывание → Новое развёртывание → Веб-приложение**. Запуск от имени: **Я**. Доступ: **Все**. Скопируй **URL веб-приложения** (…/exec).

После `setup()` в таблице появятся листы «Съели», «Покупки», «Оценки», «Мои рецепты», «Настройки». Первый лист станет «Холодильник». Твои текущие продукты остаются как были, только в конце добавится скрытая служебная колонка.

## Часть 2. Сайт на GitHub Pages

1. Зарегистрируйся на [github.com](https://github.com) (бесплатно), если ещё нет аккаунта.
2. Создай репозиторий: **+ → New repository** → имя `kukhnya` → **Public** → **Create repository**. Галочки README и прочие не ставь.
3. Загрузи туда код. Проще всего попросить Claude: «запушь в https://github.com/ТВОЙ-ЛОГИН/kukhnya». Сам: в Терминале, из папки проекта:
   ```bash
   git remote add origin https://github.com/ТВОЙ-ЛОГИН/kukhnya.git
   git push -u origin main
   ```
4. В репозитории: **Settings → Pages → Source: GitHub Actions**.
5. **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**:
   - Name: `API_URL`
   - Value: URL веб-приложения из части 1 (…/exec)

   Это не секрет — без кода доступа по нему ничего не получить. Зато потом не придётся вписывать адрес на телефоне.
6. **Actions → Deploy to GitHub Pages → Run workflow**. Через 1-2 минуты станет зелёным.
7. Адрес приложения: `https://ТВОЙ-ЛОГИН.github.io/kukhnya/`

Каждый следующий push в `main` обновляет сайт сам. На телефонах новая версия подтянется при следующем открытии.

## Часть 3. Установка на iPhone (на каждый телефон)

1. Открой `https://ТВОЙ-ЛОГИН.github.io/kukhnya/` **в Safari**. В Chrome на iPhone тоже можно, но надёжнее Safari.
2. Нажми **«Поделиться»** (квадрат со стрелкой вверх) → прокрути вниз → **«На экран «Домой»»** → **«Добавить»**.
3. Открой **«Кухню»** с экрана «Домой», не из Safari. У установленного приложения своя память, поэтому код вводится именно здесь.
4. Выбери, кто ты (Крис / Кристина), введи код доступа → **Готово**.

Если адрес скрипта не был задан в части 2, приложение попросит вставить его вручную. Удобно отправить себе URL в Телеграм и скопировать.

## Как пользоваться

- **Готовим.** Открывается первым. Сверху выбираешь завтрак, обед или ужин. Показывает блюда, для которых всё есть дома, и отдельно те, где не хватает одного продукта. Нажми на блюдо: продукты (✓ есть, ⇄ замена, ○ по желанию), шаги, 👍/👎.
- **Приготовили.** Блюдо записывается в «Съели», а продукты вычитаются из холодильника: было 6 луковиц, стало 4. Всё можно поправить перед записью.
- **Холодильник.** Пишешь «лук» и выбираешь «лук репчатый», дальше количество кнопками +/−. После магазина удобнее «Добавить списком»: по строке на продукт, вроде `картошка 8`.
- **Купить.**
  - Какой продукт откроет больше всего блюд.
  - Корзина из 5 продуктов.
  - Любимые блюда, которые давно не ели.
  - Баланс недели.
  - Отметил «купил» — приложение предложит сразу положить продукт в холодильник.
- **👎** от любого из вас: блюдо больше не предлагается на двоих. Завтраки у каждого свои.
- **Потяни экран вниз**, чтобы обновить данные с таблицы.
- **Без интернета** всё работает. Изменения отправятся сами, когда появится связь. Число в кружке у шестерёнки показывает, сколько правок ещё ждёт отправки.

- **Остатки.** После «Приготовили» укажи, сколько порций осталось. Они лягут в холодильник (🍲), а на главном экране появится «Доесть» с кнопками «−1» и «Съели 2».
- **Сроки** подставляются сами: курица +2 дня, фарш +1, молоко +7. Можно поправить.
- **Голосом:** «Привет, Siri, в холодильник» → «6 луковиц, фарш 500». Как настроить — [SIRI.md](SIRI.md).
- **Деньги.** Во вкладке «Купить» есть кнопка «+ чек»: сумма и магазин. Там же видно, сколько потрачено за неделю и за месяц. Если при покупке указать цену, приложение со временем подскажет, где этот продукт дешевле: Mercadona, Carrefour, Kuups.

**Свои рецепты** добавляй во вкладке «Рецепты» (внизу «+ Свой рецепт») или прямо в таблице, лист «Мои рецепты».
**Кладовая** (что всегда есть дома) редактируется в ⚙️ «Настройки».
**Праздники** (Mercadona закрыт) — лист «Настройки» в таблице.

## Если что-то не так

| Что видишь | Что делать |
|---|---|
| «Код не подошёл» | В Apps Script запусти функцию `showToken` и посмотри код в журнале |
| «Скрипт вернул не JSON» | Развёртывание должно быть с доступом **Все**; после правки кода — Управление развёртываниями → Новая версия |
| Изменения не доходят до таблицы | ⚙️ → «Синхронизировать» и посмотри текст ошибки |
| Продукт из таблицы не узнаётся | Назови его проще («Сметана», а не «Сметанка 15% от бабушки») или добавь в холодильник через приложение |
