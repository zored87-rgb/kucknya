# «Привет, Siri, в холодильник» — настройка за 5 минут

После настройки говоришь: **«Привет, Siri, в холодильник»**. Siri спрашивает «Что положить?», ты отвечаешь, например: **«6 луковиц, фарш 500 и молоко»**. Продукты попадают в таблицу, а при следующем открытии «Кухни» раскладываются по холодильнику с понятными названиями и сроками годности.

Настраивать нужно на каждом iPhone отдельно. Понадобятся:
- **адрес скрипта**: в приложении ⚙️ → «Голосом через Siri», нажми на поле и скопируй;
- **код доступа**: тот же, что вводили в приложении.

## Шаги

1. Открой приложение **«Команды»** (Shortcuts) → **+** в правом верхнем углу.
2. **Добавить действие** → в поиске набери **«Продиктовать текст»** → добавь.
   - Язык: **Русский**.
   - «Прекратить прослушивание»: **После паузы**.
3. **Добавить действие** → найди **«Получить содержимое URL»** → добавь.
   - В поле URL вставь **адрес скрипта** (…/exec).
   - Нажми **«Показать больше»**:
     - Метод: **POST**.
     - Текст запроса: **JSON**.
     - Добавь три поля (**+ Добавить новое поле → Текст**):

       | Ключ | Значение |
       |---|---|
       | `token` | твой код доступа |
       | `action` | `quickAdd` |
       | `text` | нажми на поле и выбери переменную **«Продиктованный текст»** |
4. **Добавить действие** → **«Получить значение из словаря»** → ключ: `message`.
5. **Добавить действие** → **«Произнести текст»**. Siri скажет «Записал в холодильник: …».
6. Сверху нажми на название команды → переименуй в **«В холодильник»** → **Готово**.

Проверь: скажи «Привет, Siri, в холодильник». Можно и без Siri: команду удобно вынести на экран «Домой» (⋯ → «На экран Домой»).

## Как говорить

Приложение понимает количество и до названия, и после. Продукты перечисляй через запятую или «и»:

- «шесть луковиц, фарш пятьсот грамм и молоко»
- «курица 800, сметана, две банки томатов»
- «полтора кило картошки»

Если Siri распознала слово странно, продукт всё равно ляжет в холодильник как есть, и его можно поправить в приложении.

## Без Siri

В приложении: Холодильник → **«Добавить списком после магазина»** → нажми 🎤 на клавиатуре и продиктуй список. Это то же самое, только внутри приложения.
