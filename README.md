# Кухня

PWA для двоих: что приготовить из того, что есть дома, что купить, чтобы открылось больше блюд, и что давно не ели.
Ставится на iPhone через «На экран Домой». Данные хранятся в Google-таблице, сервера нет.

**Как запустить:** [docs/УСТАНОВКА.md](docs/УСТАНОВКА.md) · **Все рецепты списком:** [docs/РЕЦЕПТЫ.md](docs/РЕЦЕПТЫ.md)

## Устройство

```
recipes.json            101 рецепт: продукты с количеством, замены (alt), «по желанию» (opt)
apps-script/            бэкенд в Google Apps Script (Code.gs) + README по развёртыванию
src/data/products.ts    каталог продуктов: единицы (луковицы, банки, граммы), синонимы рус/исп
src/data/ingredients.ts нормализация: ё→е, основы слов, самый конкретный синоним побеждает
src/data/quantity.ts    «6 луковиц», «½ банки», «~150 г» ↔ числа
src/logic/              что есть (availability), подбор (suggest), что купить (keyBuys), Mercadona
src/api/                IndexedDB-кэш, офлайн-очередь, синхронизация с Apps Script
src/screens/            Готовим, Холодильник, Купить, Съели, Рецепты, Настройки
tests/                  vitest: нормализация, подбор, ключевые покупки, Code.gs на фейковой таблице
scripts/mock-server.mjs локальный бэкенд: настоящий Code.gs на таблице в памяти
```

## Разработка

```bash
npm install
npm test
```

Локально с фейковым бэкендом (код доступа `test-test-test`, адрес `http://localhost:8787`):

```bash
node scripts/mock-server.mjs
```

```bash
npm run dev
```

После правки `recipes.json`:

```bash
node scripts/recipes-md.mjs > docs/РЕЦЕПТЫ.md
```

## Как подбираются блюда

- Блюдо **доступно**, если каждый обязательный продукт есть в холодильнике, есть его замена или он в кладовой. Количества хватает, если есть хотя бы 70% от нужного. Для части банки или пачки хватает самого факта, что она есть.
- **Очки:**
  - +3 за каждый продукт со сроком ≤2 дня;
  - до +3, если давно не ели;
  - −5, если ели за последние 3 дня;
  - +1.5 за каждый 👍;
  - −4, если рыба уже была на неделе;
  - +1 за овощи, если их мало на неделе;
  - −1.5 за красное мясо, если его больше 3 раз за неделю.
- **Никогда** не предлагаются: яйца как основа блюда на обед и ужин, чеддер, кислый йогурт, блюда с 👎 хоть от одного из вас (завтраки — только от себя).
- **«Купи X → откроется N блюд»:** сколько блюд станут полностью доступны, если купить только X. **Корзина:** пять продуктов, которые вместе откроют больше всего блюд.
